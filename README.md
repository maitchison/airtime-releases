# Airtime

Release builds of **Airtime**, a top-down voxel racer for MS-DOS, built for a 1996 Pentium MMX.
Written from scratch in Pascal and x86 assembler by [ninetysix](https://ninetysix.io/) (Matthew Aitchison).

Free to play. This repo holds the release builds only: every version is on the
[Releases](https://github.com/maitchison/airtime-releases/releases) page, with its changes and SHA-256 checksums.

- **Play in your browser:** https://ninetysix.io/play/airtime/
- **About the game:** https://ninetysix.io/games/airtime/
- **Latest DOS build, a stable link:** https://github.com/maitchison/airtime-releases/releases/latest/download/airtime_dos.zip

## Downloads in each release

| File | For |
|---|---|
| `airtime_dos.zip` | MS-DOS: Pentium MMX 166 or faster, 64 MB RAM, PCI VESA video card, Sound Blaster 16/AWE (or `--nosound`). Also runs in DOSBox. |
| `airtime_dos_sd.zip` | MS-DOS without the 640x480 art, a smaller download (0.9.0 on) |
| `airtime_win64.zip` | Windows 64-bit: the DOS game with DOSBox-X bundled |
